# Upstream gaps — Devnet dVPN

Changes the app would like in `dvpnd` / the program, to propose to the upstream repository.
**Nothing here is pushed without per-change owner
approval.** Until a gap is closed, the app ships the workaround listed.

**Numbered gaps (#1, #2, …) live in ONE place: an internal document (not published) (#31, Windows).** This repo cites them by number ("gap #29") and never keeps a copy, so a fix there is never stale here. Below are only the gaps found on Linux (L1, L2, …) and Linux evidence for a numbered gap.
